1. Rappel : Tout est objet, même les classes

Dans la grande majorité des langages orientés objet comme Java ou C++, les classes constituent de simples schémas structurels immuables compilés à l'avance. En Python, la réalité d'exécution est radicalement différente : les classes sont elles-mêmes des instances créées au moment de l'exécution (first-class objects).

Puisqu'une classe est un objet, elle doit logiquement être fabriquée par quelque chose : c'est précisément le rôle d'une métaclasse. Là où une instance classique hérite des méthodes de sa classe, la classe elle-même tire ses comportements d'instanciation de sa métaclasse parente.

architecture

Règle d'ingénierie & Simplicité opérationnelle

Les métaclasses sont une machinerie d'architecture réservée principalement aux créateurs de frameworks (ORM, validateurs de schémas, injecteurs de dépendances). Si __init_subclass__ (introduit par la PEP 487) ou un simple décorateur de classe répond à votre cas d'usage, privilégiez systématiquement cette approche plus lisible.

2. L'anatomie de type comme métaclasse par défaut

Par défaut, lorsque l'interpréteur CPython rencontre le mot-clé class Foo:, il invoque la fonction constructeur de la métaclasse racine type sous la signature à trois arguments fondamentaux :

type(name: str, bases: tuple[type, ...], namespace: dict[str, Any]) -> type

3. Intercepter la création de classe via __new__

python 3.12+

Le code ci-dessous démontre comment intercepter la compilation des attributs de classe pour appliquer un registre déclaratif strict avant même que la classe ne soit allouée dans le namespace global :

models_validator.py
UTF-8 • 8 lignes 
class ValidatedModelMeta(type):
    def __new__(mcs, name, bases, namespace):
        # Validation stricte des annotations de types au chargement
        fields = {k: v for k, v in namespace.get('__annotations__', {}).items()}
        namespace['_schema_fields'] = fields
        cls = super().__new__(mcs, name, bases, namespace)
        return cls

Déchiffrage du mécanisme :

  • mcs Représente la métaclasse elle-même (ValidatedModelMeta), analogue au cls dans une méthode de classe standard.
  • namespace Dictionnaire contenant les variables de classe, annotations et fonctions définies dans le bloc de classe avant instantiation.
  • super().__new__ Délègue l'allocation effective de mémoire dans l'interpréteur CPython au moteur natif de type.

4. Alternative moderne : __init_subclass__

Pour 90% des cas d'héritage dynamique où vous souhaitez simplement configurer ou valider des sous-classes lors de leur dérivation, la méthode spéciale __init_subclass__ évite tout conflit de métaclasse multiple (conflit MRO) :

class PluginBase:
    def __init_subclass__(cls, plugin_id: str, **kwargs):
        super().__init_subclass__(**kwargs)
        cls._id = plugin_id
